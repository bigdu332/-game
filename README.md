# 出货之前 · 控盘对决

试玩 06：中文股票操盘游戏，一人对战三名电脑。大单逐档改变成交价，强平后仍可反击；整个账户净资产不高于零才破产退赛。最多 48 轮，每轮 10 秒，支持手动推进与 3 秒快进。

原生 HTML / CSS / JavaScript 项目，无第三方运行时依赖、构建步骤或后端服务。`dist/` 中的文件就是可编辑的完整应用源码，并非压缩后的构建产物。

## 源码结构

```text
dist/
  index.html     页面结构、交易面板、玩法与结算弹窗
  style.css      页面样式与响应式布局
  app.js         页面交互、图表绘制、计时与状态展示
  engine.js      撮合、机器人、保证金、强平、破产和结算引擎
engine.test.mjs  引擎回归测试与 160 局模拟对账
package.json     可选的 npm 命令，无需 npm install
LICENSE          MIT 开源许可证
```

## 运行与检查

静态服务提供 `dist/`，无需安装依赖、账号或真实行情。

```bash
python3 -m http.server 8080 --directory dist
node engine.test.mjs
```

在浏览器打开 <http://localhost:8080>。本地服务需要 Python 3；测试需要 Node.js 20 或更新版本。也可以运行 `npm start` 和 `npm test`，无需安装依赖。

部署时把 `dist/` 作为网站根目录交给任意静态托管服务即可。通过 HTTP 服务打开页面，以便浏览器正确加载 JavaScript 模块。

首次打开可用 `?seed=1` 指定 1 至 4294967295 的整数种子，复现相同初始行情；点击新一局重新随机开局。固定种子只改变随机序列，不改变本金、内幕信息或规则。

## 账户、融资与保证金

- 四名玩家均以现金 20,000、空仓开始。金额滑杆取实时可用余额的 0–100%，可直接输入金额，提供 25/50/75/100% 快捷档。
- 新单提供 1–20 倍游戏杠杆，1/5/10/20 为快捷档；这套高杠杆证券游戏不声称复刻正规券商融资规则。股数 = floor（本笔预算 × 新单倍数 ÷ 参考价格）。旧单保留提交时的倍数，调节新单滑杆不改写已有仓位。
- 可抵押本金 = max（0，初始本金 + 已实现盈亏）。可用余额 = max（0，可抵押本金 − 仓位投入保证金 − 挂单冻结预算）。浮盈与空头卖出款不增加开仓本金。亏损会减少后续购买力，额度不会按轮次自动恢复。
- 下单冻结本笔预算。成交只为新开部分分配 `成交股数 × 成交价 ÷ 该单锁定倍数` 的保证金；反向交易先减仓、再开反向仓，减仓部分不需要新保证金。实际开仓不会超出该单预算。
- 同一证券只有一个净仓位。仓位权益 = 投入保证金 + 浮盈亏；仓位权益 / 持仓名义市值低于 2.5% 时撤掉普通挂单，并通过有限盘口强制平仓。系统清算未完成时不能开新仓；清算完仍有正净资产，可以再次下单。
- 手动追加为当前保证金的 50%，不超过可用余额。自动救仓默认关闭，开启后在仓位保证金率低于 5% 时尝试补到 10%。追加只转移内部额度，不改变净资产或股数。
- **所有真实成交亏损都由账户承担。**删除旧版穿仓补偿，不再有保护闲置余额的虚拟保险账户；跳空、滑点、深度不足可能使损失超过仓位保证金，甚至留下负净资产。此处强平线管理的是仓位风险，保证金不是最大亏损承诺。
- 账户净资产 = 账面现金 + 有符号股数 × 当前成交价。负现金代表融资欠款，负股数代表空头回补义务，避免重复扣除同一负债。

## 破产退赛与击败

每笔成交后检查四个账户。只有整个账户净资产 <= 0 才破产退赛。现金花完、融资额度用满、一次强平、只剩 10% 本金，都不单独导致退赛。

破产后立即取消普通挂单、禁止自主交易、停用机器人新单；剩余头寸只能由系统减仓清算。退赛是本局的最终状态，后续价格反弹也不恢复资格。虚拟负债在本局结算中保留，不会由系统补钱抹除。

若某参赛者的主动成交使另一账户净资产从正数跌到不高于零，记录一次击败；本人界面显示“恭喜你击败了某某某！”。不为已有破产、自己的风险、无法归因的行情、强平连锁或最终兑付冒领击败。每个退赛事件只触发一次。玩家自己破产后显示退赛弹窗，可以继续观战或新开一局。

仅剩一位未退赛玩家时提前结束并按最终兑付价结算。否则第 48 轮按存活者结算净资产排序；退赛者位于存活者之后，晚退赛者优先。最后结算仍可能使账户破产，全员破产则无人获胜。

## 操盘、挂单与成交

有限流动性池初始现金 400,000、库存 4,000 股，不能无限买卖。每边 24 档报价，近盘薄、远盘厚，最远相对报价中枢约 19.6%。足够大的委托能吃穿多档，而不是被原先约 2.8% 的浅盘口限制。机器人也按自己的杠杆放大意向数量，并接受相同的预算与风险检查。

市价单每轮以轮初价格的 ±20% 为成交保护范围；这不是全市场涨跌停或保证一定成交的承诺。持久市价单的下一轮保护范围随新行情更新。限价按指定价格约束。

玩家市价单与限价单的未成交余量都跨轮保留：原编号、原创建轮、原锁定倍数、剩余数量、剩余预算不因换轮丢失。预算不足只暂停，不自动撤单或补钱。全部成交、主动撤单、主动减仓/平仓时撤单、强平风控、破产风控或收盘会结束委托。每人最多五笔普通挂单。系统强平单只能减仓，不能翻成反向仓位。

每笔真实成交转移现金和股票，不允许自成交。盘中所有参与者现金之和、股票净股数守恒。收盘由发行方按最终兑付价兑付全市场净库存；对应账面现金总和增加 `initialShares × finalValue`，负债不被豁免。

## 公开信息与终局

自己的准确持仓、成本、盈亏、保证金、收益率、强平线完全可见。对手公开上一轮净流向、成交规模区间、方向和资金压力，保留近三轮；破产状态和击败记录公开。当前未成交意图、准确资金与成本不公开。

最终兑付价在开局生成（80–120）。第 12/24/36 轮更新公开估值区间，第 44 轮确认兑付价；机器人只读相同公开信息和自身状态。最终按兑付价结算，最后成交价不能直接变成结算收益。

## 验证与范围
